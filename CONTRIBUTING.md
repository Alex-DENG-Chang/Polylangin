# Contributing

Thanks for trying Polylangin.

- Open an issue before large changes; describe the platform (macOS version or
  Linux distro/IM framework) and input sequence.
- Keep changes small and focused; include reproduction steps for behavior changes.
- Run the Linux core tests: `bash linux/run-tests.sh` or
  `python3 -m unittest discover -s linux/tests`.
- Never commit typing logs, credentials, signing certificates, or user-specific
  paths.
- By contributing you agree your changes are licensed under GPL-3.0.
