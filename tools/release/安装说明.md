# Polylangin（macOS，Apple Silicon）

一个本地混合语言输入法：中文 / English / Français 混着打，不需要切换输入模式。
基于 Squirrel 1.1.2 + Rime（GPL-3.0），内置 rime-ice 词库 + 模糊音（仅后鼻音）+ 英文/法文纠错。

## 安装

1. 解压后双击运行 `install.sh`（或在终端里 `bash install.sh`）。
   - 如果 macOS 提示脚本/应用无法验证开发者：
     系统设置 → 隐私与安全性 → 仍要打开；或先执行：
     `xattr -dr com.apple.quarantine ~/Library/Input\ Methods/Polylangin.app`
2. 首次启动会在 `~/Library/Rime-Polylangin` 重建词库，等约 1 分钟。
3. 菜单栏输入源里选 **Polylangin**（或系统设置 → 键盘 → 输入法 → + 添加 Polylangin）。
4. 中文直接用拼音连打，空格确认；英文/法文直接打，空格确认并自动补空格。
   模糊音只开了前后鼻音（an/ang、en/eng、in/ing、ian/iang、uan/uang）。

## 常用按键

- 空格：确认当前候选（英文/法文词会补一个空格）
- Enter：原样提交你打的拉丁字母（英文兜底/纠错逃生口）
- 数字 1–9：选择当前页候选
- ←/→：在所有候选里移动（跨页自动翻）
- ↓/↑：整页翻候选
- Esc：清空当前输入；双击 Tab：清空
- 英文拼写错误、法语拼写错误、拼音相邻字母打反会自动纠正

## 打字日志（用于改进输入法）

输入法会自动记录本地打字日志，用于之后分析改进（不会上传）：

- 目录：`~/Desktop/Polylangin-logs/`，每天一个 `YYYY-MM-DD.jsonl`
- 记录内容：按键、退格/连续退格、上屏词（原文→结果）、语言（中/英/法）、
  候选翻页、自动纠错、放弃的输入、使用到的 app
- 密码框（secure input）不会记录
- 如果桌面上没有这个目录，说明桌面权限没给；日志会回退到
  `~/Library/Logs/Polylangin/`

下班前收集日志（会 zip 到桌面）：

```bash
bash collect-typing-logs.sh
```

然后把桌面上的 `Polylangin-typing-logs-*.zip` 拷走即可。
分析完成后建议删除日志（里面包含你打的文字）。

## 卸载

```bash
rm -rf ~/Library/Input\ Methods/Polylangin.app
rm -rf ~/Library/Rime-Polylangin
```
然后在系统设置 → 键盘 → 输入法里移除 Polylangin。
